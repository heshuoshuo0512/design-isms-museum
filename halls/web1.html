历史档案

Web 1.0 美学指向 1990 年代中后期到 2000 年代初的早期大众网页：静态 HTML、表格布局、个人主页、门户首页和留言簿构成了网络的基本建筑。GeoCities、Tripod 等服务让用户自己选择背景、GIF、横幅和访客计数器；蓝色下划线链接、系统字体、滚动文字与“施工中”图标则成为共同记忆。今天的 Old Web 复兴把这些粗糙但有主人的痕迹重新带回网页，强调可见的作者性和非算法化的漫游。

Traits

风格特征

  • 表格布局 — table 与固定宽度把页面切成明确栏目
  • 系统字体 — Times New Roman、Arial 和 Courier 直接暴露浏览器环境
  • GIF 动画 — 闪烁、滚动、旋转图像负责吸引注意
  • 蓝色链接 — 下划线链接与访问状态构成导航地图
  • 个人痕迹 — 计数器、留言簿、徽章和施工中图标说明“有人在这里”)
