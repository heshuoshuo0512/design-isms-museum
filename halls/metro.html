Metro UI · 2010

“内容优先,界面像城市一样清晰。”

20102010 · Windows Phone 7 设计语言

Metro 把屏幕当作一座有清晰路牌的城市:大字负责指路,动态磁贴持续更新,颜色和留白让信息先于容器被看见。它让界面少一点拟物,多一点公共信息系统的节奏。

Archive

历史档案

Metro 是微软在2010年前后为 Zune 与 Windows Phone 7 形成的设计语言,随后进入 Windows 8。它受瑞士国际主义、机场标牌和公共交通信息系统启发,用大字号、平面色块、留白和动态磁贴组织信息;内容本身不必被厚重的容器包住。Windows 8 的全屏磁贴让这种语法进入桌面争论,之后微软逐步转向 Fluent,但 Metro 对移动界面、信息架构和动效的影响仍然清晰。

Traits

风格特征

  • 大字号排版 — 标题像城市路牌,承担方向与层级
  • 动态磁贴 — 信息在入口处更新,减少层层打开
  • 平面色块 — 纯色承担分类和识别
  • 内容优先 — 弱化容器,让文字与图像直接出现
  • 网格与留白 — 规整模块保留公共系统的秩序感
