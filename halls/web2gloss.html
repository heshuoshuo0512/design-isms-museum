Web 2.0 光泽

Web 2.0 Gloss · 2005

“把每一次点击都包上一层亮晶晶的乐观。”

20052004–2008 · 博客与社交网站

圆角、渐变、倒影和一颗像糖果一样的按钮,构成了宽带互联网早期的公共客厅。

Archive

历史档案

Web 2.0 光泽是宽带互联网进入大众生活时的视觉语气。2004 年前后,博客、社交网络与小型创业公司的首页纷纷使用圆角面板、蓝色渐变、玻璃高光、倒影和糖果色按钮,把「点击」包装成一种友好而有奖励感的动作。它延续了拟物化的触感,又把品牌、社区与用户生成内容放进更轻快的网页框架,在 2000 年代后期逐渐被扁平化设计取代。

Traits

风格特征

  • 高光渐变 — 顶部白色高光与纵向色阶制造塑料感
  • 圆角胶囊 — 按钮、标签和面板都拥有柔软的圆角
  • 倒影与阴影 — 半透明反射和柔和投影暗示真实材质
  • 糖果色 — 天蓝、亮粉、橙黄组成乐观的网络调色板
  • 可点击触感 — 悬停、按下和闪烁把交互做成视觉奖励
