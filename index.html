CURATOR'S NOTES

策展笔记 · 如何"用"这些主义

Ⅰ

风格是修辞,不是语法

新粗野的硬阴影适合独立电商的态度,瑞士网格适合财报的克制。先想清楚要说"什么",再决定用"哪种口音"说。风格选错,内容再对也像念错台词。

Ⅱ

混搭要有主次

暗色底 + 极光渐变 + Bento 网格 = 当代 SaaS 标配。但一个页面只能有一个主角。选定一个基调占 70%,其余主义当调料,撒太多就是极繁,撒太少就是平庸。

Ⅲ

可用性是不可让渡的底线

新拟态死于对比度,酸性设计死于可读性。可以在 hero 区放肆,但正文对比度 ≥ 4.5:1、字号 ≥ 14px、可点击区域 ≥ 44px 这三条,任何主义都无权违反。

Ⅳ

一切主义皆可 CSS

本馆 80 个展厅 0 张图片:毛玻璃是 backdrop-filter,硬阴影是 box-shadow,故障是 clip-path,极光是 radial-gradient + blur。打开 DevTools,把任何一件标本的样式偷走。
