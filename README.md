# 主义馆 · ISM MUSEUM

一个纯 HTML/CSS/JavaScript 的前端设计主义线上展馆。

- 80 个设计主义展厅
- 大厅、4 行轮播长廊、真实年份时间轴
- 每个展厅包含历史、案例、特征、代码指纹和 CSS 交互标本
- 零框架、零图片、零运行时外部请求
- 首页新增“课程 ↔ 前端专业”双向赋能展区，提供全局知识书的局部预览
- `knowledge.html` 为《现代设计全书》：以 80 个设计方向为主体，按历史主线、设计索引和课内补充组织内容
- 课内八个母题作为全书的阅读镜头，补充每条设计档案的课内关系、前端转译与课程回写，而不是替代全局设计史
- 全书采用目录、历史弧线、课内章节和逐条阅读器，避免把 80 条内容一次性堆成卡片墙

## 本地运行

```bash
python3 -m http.server 8787
```

打开 <http://127.0.0.1:8787/>。

## 生成展厅

修改 `data.py` 或 `build.py` 后执行：

```bash
python3 build.py
```

## GitHub Pages

`main` 分支推送会由 `.github/workflows/pages.yml` 自动部署到 GitHub Pages。
