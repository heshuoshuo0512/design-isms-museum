# 主义馆 · ISM MUSEUM

一个纯 HTML/CSS/JavaScript 的现代设计与设计主义历史线上展馆。

- 80 个设计主义展厅
- 大厅、4 行轮播长廊、真实年份时间轴
- 每个展厅包含历史、案例、特征、代码指纹和 CSS 交互标本
- 零框架、零图片、零运行时外部请求
- 首页提供课程 ↔ 前端的双向赋能预览，但它只是全书的应用补充层
- `knowledge.html` 为《现代设计全书》：以 80 个设计方向为主体，用 9 个现代设计史事件讲清事件本身、历史背景、主义形成、设计影响、历史反思与当代转译
- 每个方向先展示自己的完整历史叙事、关键历史节点、形式方法和代表案例，再连接横向历史事件与教学任务
- 课程与前端内容只是完整方向叙事中的一层：用于引导实践、教授设计和回写评价，不替代该方向本身的历史

## 本地运行

```bash
python3 -m http.server 8787
```

打开 <http://127.0.0.1:8787/>。

## 生成展厅

修改 `data.py` 或 `build.py` 后执行：

```bash
python3 build.py
```

## GitHub Pages

`main` 分支推送会由 `.github/workflows/pages.yml` 自动部署到 GitHub Pages。
