# 主义馆 · ISM MUSEUM

一个纯 HTML/CSS/JavaScript 的前端设计主义线上展馆。

- 80 个设计主义展厅
- 大厅、4 行轮播长廊、真实年份时间轴
- 每个展厅包含历史、案例、特征、代码指纹和 CSS 交互标本
- 零框架、零图片、零运行时外部请求
- 首页新增“课程 ↔ 前端专业”双向赋能展区，提供全局知识书的局部预览
- `knowledge.html` 为《现代设计全书》：以 80 个设计方向为主体，用 9 个课程历史事件把设计史、设计影响和教学实践串起来
- 每个事件依次展示“历史追问 → 对设计的影响 → 设计引导 → 如何教授设计”，再跳转到关联的设计档案
- 课内母题退到事件章节中的连接维度；每条设计档案仍保留课内关系、前端转译与课程回写

## 本地运行

```bash
python3 -m http.server 8787
```

打开 <http://127.0.0.1:8787/>。

## 生成展厅

修改 `data.py` 或 `build.py` 后执行：

```bash
python3 build.py
```

## GitHub Pages

`main` 分支推送会由 `.github/workflows/pages.yml` 自动部署到 GitHub Pages。
