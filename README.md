# 主义馆 · ISM MUSEUM

一个纯 HTML/CSS/JavaScript 的现代设计与设计主义历史线上展馆。

- 首页只保留“从现代设计史开始”为主路线，并提供“按设计主义浏览”和“随机进入一个展厅”两个次入口
- `knowledge.html` 为统一全书入口：默认先读 14 个通史章节，再进入 9 个横向历史事件和 80 个方向索引
- 历史路线拆成三个互斥阅读层：通史主干、横向事件、设计实验，避免三组长内容同时堆叠在一个页面
- 每个方向都有独立展厅；首页的 80 个展厅索引默认收起，避免与历史入口竞争
- 大厅、长廊、时间轴和全书不再作为平级主入口；它们是历史路线之后的支线
- 80 个设计主义展厅
- 大厅、4 行轮播长廊、真实年份时间轴
- 每个展厅按历史档案、人物/转折/传播、设计语言、案例、批评与争议、当代影响、当代转译、CSS 标本排列
- 零框架、零图片、零运行时外部请求
- 全书历史路线之后包含“现代设计美学”双向实验：瑞士网格 → 布局约束，包豪斯模块 → 组件复用，格式塔分组 → 感知规则，交互设计 → 状态与恢复
- 实验流程是设计传统 → 可执行规则 → 计算布局与指标 → 读者指出层级/分组/装饰/反馈问题 → 改写目标函数或约束 → 新输出；它改善人机系统的目标，不声称提高 CPU 或算法速度
- 该实验是当前页面会话中的真实前端闭环；反馈不持久化，不伪装成数据库或自动训练系统
- 首页不再承载课程 ↔ 前端的交互预览；课程关系保留在全书和独立展厅的应用补充层
- `knowledge.html` 现在按六卷组织：通史主干、设计实践史、全球设计史、思想与方法、80 个方向档案、作品/人物/机构/来源
- 通史页提供 8 条设计实践线、8 个全球与权力关系档案、8 个机构节点和 18 条本地静态延伸阅读
- `book_data.py` 独立保存通史、卷结构、实践字段、全球区域、机构档案和书目，避免把全书继续塞进 80 个方向记录
- `book_archives.py` 为 14 个通史章节提供结构化档案坐标：作品/项目、年代、地点、人物、机构、设计作用与对应书目；页面仍明确这些条目是查档入口，不是穷尽的馆藏目录

## 本地运行

```bash
python3 -m http.server 8787
```

打开 <http://127.0.0.1:8787/>。

## 生成展厅

修改 `data.py` 或 `build.py` 后执行：

```bash
python3 build.py
```

## GitHub Pages

`main` 分支推送会由 `.github/workflows/pages.yml` 自动部署到 GitHub Pages。
