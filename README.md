# 主义馆 · ISM MUSEUM

一个纯 HTML/CSS/JavaScript 的现代设计与设计主义历史线上展馆。

- 80 个设计主义展厅
- 大厅、4 行轮播长廊、真实年份时间轴
- 每个展厅包含历史、历史深描、案例、特征、代码指纹和 CSS 交互标本
- 零框架、零图片、零运行时外部请求
- 首页提供课程 ↔ 前端的双向赋能预览，但它只是全书的应用补充层
- `knowledge.html` 为《现代设计全书》：以 80 个设计方向为主体，每个方向拆成起源、人物、转折、传播、争议和当代影响六个历史栏目
- 全书另有 9 个现代设计史事件章节，分别讲事件本身、背景、参与者、关键转折、传播路径、历史结果、争议、影响和教学思考
- 课程与前端内容只是完整方向叙事中的一层：用于引导实践、教授设计和回写评价，不替代该方向本身的历史

## 本地运行

```bash
python3 -m http.server 8787
```

打开 <http://127.0.0.1:8787/>。

## 生成展厅

修改 `data.py` 或 `build.py` 后执行：

```bash
python3 build.py
```

## GitHub Pages

`main` 分支推送会由 `.github/workflows/pages.yml` 自动部署到 GitHub Pages。
